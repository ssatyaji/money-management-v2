## Latar Belakang & Masalah

Ditemukan **2 bug/kekurangan UX** pada web Zayn Finance:

### BUG-1: PWA Install Prompt — Ikon Berantakan & Tombol Close Tidak Terlihat

**Gejala:**
- Ikon pada popup install PWA muncul sebagai teks mentah (misalnya tulisan `install_mobile` bukan ikon).
- Tombol "Nanti Saja" (close/dismiss) terpotong atau tidak terlihat sehingga user tidak bisa menutup popup tanpa meng-install.
- **CATATAN:** Masalah ikon ini juga terlihat di seluruh aplikasi (tombol login "Masuk arrow_forward", ikon password "visibility", dll). Ini adalah masalah **global** karena font Material Symbols Outlined gagal dimuat.

**Root Cause:**
1. **Font Material Symbols gagal dimuat.** File `frontend/src/app/layout.tsx` (baris 41) memuat font via `<link>` tag di `<head>`:
   ```html
   <link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:wght,FILL@100..700,0..1&display=swap" rel="stylesheet" />
   ```
   URL ini menggunakan parameter `wght,FILL` yang bisa menyebabkan masalah pada beberapa versi browser atau ketika ada `Content-Security-Policy` yang memblokir external fonts. Selain itu, loading via external CDN bisa gagal jika offline (ironis untuk PWA). Font tidak pernah ter-load sehingga semua `<span class="material-symbols-outlined">` merender teks mentah.

2. **Layout popup PWA** (`install-prompt.tsx` baris 54) menggunakan layout `flex gap-4` tetapi pada layar kecil, ikon dan konten bisa saling mendesak sehingga tombol "Nanti Saja" terpotong atau tidak terlihat.

**File yang terdampak:**
- `frontend/src/app/layout.tsx` — import font
- `frontend/src/components/pwa/install-prompt.tsx` — komponen popup
- `frontend/src/app/globals.css` — CSS rule Material Symbols

### TASK-1: Fix Pemuatan Font Material Symbols Outlined

**File:** `frontend/src/app/layout.tsx`

#### Masalah (kode sekarang, baris 40-42):
```tsx
<head>
  <link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:wght,FILL@100..700,0..1&display=swap" rel="stylesheet" />
</head>
```

#### Perbaikan:
Ganti URL font Google agar lebih reliable. Masalahnya adalah parameter axes `wght,FILL` menggunakan format yang bisa gagal. Gunakan format yang lebih standar dan tambahkan `crossOrigin` agar browser bisa melakukan preconnect yang benar.

Ganti baris 40-42 dengan:
```tsx
<head>
  <link rel="preconnect" href="https://fonts.googleapis.com" />
  <link rel="preconnect" href="https://fonts.gstatic.com" crossOrigin="anonymous" />
  <link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200&display=swap" rel="stylesheet" />
</head>
```

#### Penjelasan perubahan:
- Tambah `preconnect` ke `fonts.googleapis.com` dan `fonts.gstatic.com` untuk mempercepat loading font
- Perbaiki URL font: tambahkan parameter `opsz` dan `GRAD` yang merupakan format axes standar untuk Material Symbols Outlined. Format asli hanya menentukan `wght,FILL` dan mungkin gagal karena server Google memerlukan semua 4 axes (opsz, wght, FILL, GRAD) dalam urutan tertentu
- Ini akan memastikan ikon-ikon seperti `install_mobile`, `visibility`, `arrow_forward`, dll. ditampilkan dengan benar di seluruh aplikasi

#### Verifikasi:
1. Buka halaman login di browser
2. **Ekspektasi:** Ikon pada tombol "Masuk" harus berupa ikon panah (bukan teks "arrow_forward")
3. **Ekspektasi:** Ikon visibility pada field password harus berupa ikon mata (bukan teks "visibility")
4. **Ekspektasi:** Ikon pada PWA install prompt harus berupa ikon handphone (bukan teks "install_mobile")

### TASK-2: Perbaiki Layout & Styling PWA Install Prompt

**File:** `frontend/src/components/pwa/install-prompt.tsx`

#### Masalah:
1. Ikon menggunakan `material-symbols-outlined` yang bisa fallback ke teks jika font gagal dimuat
2. Tidak ada tombol close (X) yang jelas — hanya "Nanti Saja" yang sering tidak terlihat karena layout flex
3. Layout button dalam satu baris bisa overflow pada layar kecil

#### Perbaikan — ganti seluruh isi file dengan:

```tsx
'use client';

import { useState, useEffect } from 'react';
import { Button } from '@/components/ui/button';
import { Download, X } from 'lucide-react';

export function InstallPrompt() {
  const [isReadyForInstall, setIsReadyForInstall] = useState(false);
  const [deferredPrompt, setDeferredPrompt] = useState<any>(null);
  const [isDismissed, setIsDismissed] = useState(false);

  useEffect(() => {
    // Check if app is already installed or if user dismissed recently
    if (window.matchMedia('(display-mode: standalone)').matches) {
      return;
    }
    
    if (localStorage.getItem('pwa_prompt_dismissed')) {
      return;
    }

    const handleBeforeInstallPrompt = (e: Event) => {
      e.preventDefault();
      setDeferredPrompt(e);
      setIsReadyForInstall(true);
    };

    window.addEventListener('beforeinstallprompt', handleBeforeInstallPrompt);

    return () => {
      window.removeEventListener('beforeinstallprompt', handleBeforeInstallPrompt);
    };
  }, []);

  const downloadApp = async () => {
    if (!deferredPrompt) return;
    deferredPrompt.prompt();
    const { outcome } = await deferredPrompt.userChoice;
    if (outcome === 'accepted') {
      setIsReadyForInstall(false);
    }
    setDeferredPrompt(null);
  };

  const dismissPrompt = () => {
    setIsReadyForInstall(false);
    setIsDismissed(true);
    localStorage.setItem('pwa_prompt_dismissed', 'true');
  };

  if (!isReadyForInstall || isDismissed) return null;

  return (
    <div className="fixed bottom-24 sm:bottom-6 left-4 right-4 sm:left-auto sm:right-6 sm:max-w-sm z-50 animate-in slide-in-from-bottom-5">
      <div className="relative bg-card border border-border shadow-[0px_8px_24px_rgba(26,43,60,0.12)] rounded-2xl p-4">
        {/* Close button (X) — selalu terlihat di pojok kanan atas */}
        <button
          onClick={dismissPrompt}
          className="absolute top-3 right-3 w-6 h-6 flex items-center justify-center rounded-full text-muted-foreground hover:text-foreground hover:bg-muted transition-colors"
          aria-label="Tutup"
        >
          <X className="w-4 h-4" />
        </button>

        <div className="flex gap-3 pr-6">
          {/* Ikon menggunakan Lucide (tidak tergantung Material Symbols font) */}
          <div className="w-11 h-11 rounded-xl bg-primary/10 flex items-center justify-center shrink-0">
            <Download className="w-5 h-5 text-primary" />
          </div>
          <div className="flex-1 min-w-0">
            <h3 className="font-semibold text-sm">Install Aplikasi</h3>
            <p className="text-xs text-muted-foreground mt-0.5">
              Akses lebih cepat & dapat digunakan secara offline.
            </p>
          </div>
        </div>

        {/* Tombol aksi — satu baris di desktop, stack di mobile kecil */}
        <div className="flex gap-2 mt-3">
          <Button size="sm" onClick={downloadApp} className="flex-1 h-8 text-xs rounded-full">
            Install Sekarang
          </Button>
          <Button size="sm" variant="outline" onClick={dismissPrompt} className="flex-1 h-8 text-xs rounded-full border-border">
            Nanti Saja
          </Button>
        </div>
      </div>
    </div>
  );
}
```

#### Penjelasan perubahan:
1. **Ganti ikon Material Symbols → Lucide `Download`**: Lucide sudah terinstall di project dan tidak tergantung pada external font. Jika font gagal dimuat, ikon Lucide tetap tampil karena menggunakan SVG
2. **Tambah tombol close (X)** di pojok kanan atas menggunakan Lucide `X` icon — selalu terlihat dan jelas
3. **Perbaiki layout**: tambah `relative` pada container dan `pr-6` pada content agar tidak tertutup tombol X
4. **Perbaiki responsive**: gunakan `flex-1` pada tombol agar seimbang di semua ukuran layar
5. **Hapus `w-full`** pada tombol karena `flex-1` sudah mencukupi
6. **Perbaiki ukuran ikon container** dari `w-12 h-12` → `w-11 h-11` agar lebih proporsional

#### Verifikasi:
1. Buka aplikasi di browser (harus belum pernah dismiss prompt, atau clear localStorage `pwa_prompt_dismissed`)
2. **Ekspektasi:** Popup muncul di pojok kanan bawah

4. **Ekspektasi:** Ada tombol X di pojok kanan atas popup

### TASK-3: Buat Komponen LogoutDialog (Reusable)

**File:** `frontend/src/components/shared/logout-dialog.tsx` [NEW]

#### Kode lengkap file baru:

```tsx
'use client';

import {
  Dialog,
  DialogContent,
  DialogHeader,
  DialogTitle,
  DialogDescription,
  DialogFooter,
} from '@/components/ui/dialog';
import { Button } from '@/components/ui/button';
import { LogOut } from 'lucide-react';

interface LogoutDialogProps {
  open: boolean;
  onOpenChange: (open: boolean) => void;
  onConfirm: () => void;
  isLoading?: boolean;
}

export function LogoutDialog({ open, onOpenChange, onConfirm, isLoading }: LogoutDialogProps) {
  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent className="sm:max-w-md" showCloseButton={false}>
        <DialogHeader>
          <div className="mx-auto sm:mx-0 w-12 h-12 rounded-full bg-destructive/10 flex items-center justify-center mb-2">
            <LogOut className="w-6 h-6 text-destructive" />
          </div>
          <DialogTitle>Konfirmasi Keluar</DialogTitle>
          <DialogDescription>
            Apakah Anda yakin ingin keluar dari akun Anda? Anda perlu login kembali untuk mengakses aplikasi.
          </DialogDescription>
        </DialogHeader>
        <DialogFooter className="mt-4 gap-2 sm:gap-0">
          <Button
            variant="outline"
            onClick={() => onOpenChange(false)}
            disabled={isLoading}
            className="rounded-full"
          >
            Batal
          </Button>
          <Button
            variant="destructive"
            onClick={onConfirm}
            disabled={isLoading}
            className="rounded-full gap-2"
          >
            {isLoading ? (
              <>
                <span className="w-4 h-4 border-2 border-destructive-foreground/30 border-t-destructive-foreground rounded-full animate-spin" />
                Keluar...
              </>
            ) : (
              <>
                <LogOut className="w-4 h-4" />
                Ya, Keluar
              </>
            )}
          </Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
}
```

#### Penjelasan:

- Menggunakan `Dialog` component yang sudah ada di project
- Props `open`, `onOpenChange`, `onConfirm` mengikuti pola yang sama dengan Dialog lain di project
- Menggunakan Lucide `LogOut` icon (bukan Material Symbols)
- Ada loading state (`isLoading`) untuk saat proses logout sedang berjalan
- Desain visual: ikon bulat merah, judul "Konfirmasi Keluar", deskripsi, dan dua tombol (Batal & Ya, Keluar)

#### Langkah 3 — Modifikasi handleLogout
Ganti method `handleLogout` yang ada (baris 44-47):
```typescript
// SEBELUM:
const handleLogout = async () => {
  await logout();
  router.push('/login');
};
```

Menjadi:
```typescript
// SESUDAH:
const handleLogout = () => {
  setShowLogoutDialog(true);
};

const confirmLogout = async () => {
  setIsLoggingOut(true);
  try {
    await logout();
    router.push('/login');
  } finally {
    setIsLoggingOut(false);
    setShowLogoutDialog(false);
  }
};
```

#### Langkah 4 — Tambahkan LogoutDialog component di JSX
Tepat sebelum penutup `</header>` (baris 143), tambahkan komponen LogoutDialog:
```tsx
      {/* Logout Confirmation Dialog */}
      <LogoutDialog
        open={showLogoutDialog}
        onOpenChange={setShowLogoutDialog}
        onConfirm={confirmLogout}
        isLoading={isLoggingOut}
      />
    </header>
```

> ⚠️ **PENTING:** `LogoutDialog` harus berada di dalam `return()` tapi SEBAGAI SIBLING dari `<header>`, bukan di dalamnya. Karena `<header>` adalah elemen HTML dan Dialog menggunakan Portal. Solusi: bungkus return value dengan `<>...</>` (Fragment).

Jadi, ubah return statement menjadi:
```tsx
return (
  <>
    <header className="sticky top-0 z-50 ...">
      {/* ... existing content ... */}
    </header>

    {/* Logout Confirmation Dialog */}
    <LogoutDialog
      open={showLogoutDialog}
      onOpenChange={setShowLogoutDialog}
      onConfirm={confirmLogout}
      isLoading={isLoggingOut}
    />
  </>
);
```

#### Penjelasan:
- `handleLogout` sekarang hanya menampilkan dialog konfirmasi
- `confirmLogout` adalah fungsi yang benar-benar melakukan logout (dipanggil ketika user klik "Ya, Keluar" di dialog)
- Dialog menggunakan Portal sehingga tidak masalah diletakkan di mana saja di tree

#### Verifikasi:
